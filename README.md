IoT-Based Precision Agriculture Monitoring System 🌱

📌 Project Overview

This project aims to monitor agricultural environmental conditions using IoT technology. It uses an ESP32 microcontroller, a DHT11 sensor, and the Blynk IoT platform to monitor temperature and humidity.

Soil moisture and NPK nutrient monitoring are planned for future development.

🎯 Objectives

- Monitor temperature and atmospheric humidity.
- Display sensor readings on the Blynk dashboard.
- Plan soil moisture and NPK nutrient monitoring.
- Support smarter agricultural decisions using IoT.

🛠️ Technologies Used

- ESP32
- DHT11 Temperature and Humidity Sensor
- Arduino IDE
- Blynk IoT Platform
- Embedded C/C++

⚙️ Current Features

- Real-time temperature monitoring.
- Real-time atmospheric humidity monitoring.
- Blynk dashboard integration.

🔮 Future Scope

- Soil moisture monitoring.
- NPK nutrient analysis.
- Additional agricultural monitoring features.
